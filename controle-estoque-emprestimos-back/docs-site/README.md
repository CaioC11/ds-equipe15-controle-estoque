# @cincoders/docs

Documentation site for the Cincoders NestJS boilerplate, built with [Next.js](https://nextjs.org/) and [Fumadocs](https://fumadocs.dev/).

Content lives under `content/docs/` as MDX.

```bash
npm run dev
```

## Structure

- `content/docs/`: Documentation pages (MDX).
- `src/lib/source.ts`: Content source adapter.
- `src/lib/layout.shared.tsx`: Shared layout options.
